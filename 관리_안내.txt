보안관 설치일정 알림 — 노트북 관리 본부 안내
==================================================

[이 폴더가 하는 일]
이 폴더가 '원본'입니다. 여기서 고치고 버튼을 누르면 GitHub 를 거쳐 각 PC 가 스스로 업데이트합니다.

  노트북(이 폴더) ── 시험배포.bat ──> GitHub release/beta   ──> 우리 마지 PC (시험판 주소)
                  └─ 전체배포.bat ──> GitHub release/stable ──> 모든 업체 PC (전체 주소)

  - 각 PC 는 6시간마다 확인해서, 바뀐 파일만 내려받아 교체하고 다시 켜집니다.
  - 내려받은 파일의 지문이 하나라도 틀리면 아무것도 바꾸지 않습니다.
  - 바꾸기 전 파일은 그 PC 의 C:\bak_watch\backup\ 에 남습니다.
  - config.ini(설정·비밀번호 관련), state.json(기록), 3_run.bat(실행 중인 창) 은 절대 바꾸지 않습니다.
  - 필요한 부품이 새로 생기면, 그 PC 에 없는 것만 자동 설치합니다.


[폴더 구성]
  src\          ← 프로그램 원본. 고치는 곳은 여기뿐
  tests\        ← 자동 시험 (배포 전에 자동으로 돌아감)
  tools\        ← 배포 도구 (건드릴 필요 없음)
  release\      ← 배포 버튼이 자동으로 만드는 곳 (직접 고치지 말 것)
  처음_설정.bat  ← 맨 처음 한 번만
  시험배포.bat   ← 고친 걸 우리 마지 PC 에만 먼저 보냄
  전체배포.bat   ← 시험배포한 그대로를 모든 업체에 보냄
  되돌리기.bat   ← 전체배포 후 문제 생기면 직전 버전으로
  검사만.bat     ← 올리지 않고 검사만


[처음 한 번 — 30분]
1) GitHub 가입 (github.com) → 오른쪽 위 프로필 → Settings → Password and authentication
   → Two-factor authentication 켜기 (필수: 이 계정이 털리면 모든 업체 PC 가 위험)
2) GitHub 에서 + → New repository
   - 이름: bak-watch / Public 선택 / README·.gitignore 추가 안 함(빈 상태) → Create repository
3) 노트북에 Git 설치: 시작 메뉴에서 PowerShell 열고  winget install --id Git.Git -e
4) 노트북에 Python 설치 (없다면): python.org → Python 3.13 → 첫 화면 "Add python.exe to PATH" 체크
5) 처음_설정.bat 실행 → GitHub 아이디·이메일 입력 → GitHub 로그인 창이 뜨면 로그인
   → 끝나면 업데이트주소.txt 에 주소 2개가 생김
6) 우리 마지 PC 의 C:\bak_watch\config.ini 맨 아래 [admin] 칸:
      update_url = (업데이트주소.txt 의 '시험판 주소')
      auto_update = yes
   다른 업체 PC 에는 '전체 주소'를 넣습니다.
7) 시험배포.bat → 전체배포.bat 한 번씩 해서 첫 배포를 만들어 둠

※ 마지 PC 에 아직 '멈춤 수정판(업데이트_적용.bat)'을 안 했다면 그것부터 한 번 손으로 적용하세요.
  (그 전 버전은 3_run.bat 이 감시기를 켜지 않기 때문. 이후부터는 전부 자동)


[평소에 고칠 때]
1) Claude 에게: "노트북의 보안관알림_관리 폴더 열어서 src 고쳐줘 — (원하는 내용)"
   또는 직접 src 안의 파일 수정
2) 시험배포.bat  → 마지 PC 가 6시간 안에 받음
   (바로 받게 하려면 마지 PC 의 검은 창을 닫고 3_run.bat 다시 실행)
3) 하루 써 보고 이상 없으면 → 전체배포.bat (y 입력)
4) 관리 채널(#대리점-관리)에 업체별 "업데이트 완료"가 오는지 확인
5) 문제가 생기면 → 되돌리기.bat → 고쳐서 다시 2)부터


[배포 버튼이 막는 것]
- src 에 config.ini 가 들어 있으면 중단
- 파일 안에 Slack Webhook 주소, Slack 토큰, 비밀번호, 봇 토큰 값이 있으면 중단
  (공개 저장소라 누구나 볼 수 있기 때문)
- 문법 오류, 자동 시험 실패 시 중단
- 시험배포 후 파일을 또 고쳤으면 전체배포 중단 → 시험배포부터 다시
- 같은 버전 전체배포 두 번 → 중단


[막지 못하는 것 — 꼭 지킬 것]
- 문법은 맞지만 동작이 틀린 코드는 못 막습니다 → 반드시 시험배포 → 마지 PC 하루 → 전체배포 순서
- GitHub 계정 보안 → 2단계 인증 필수, 비밀번호 공유 금지
- 업체 config.ini, 토큰, 비밀번호는 이 폴더에 절대 두지 않기
- 업체 PC 가 꺼져 있으면 업데이트도 못 받음 → 켜졌을 때 6시간 안에 받음


[업데이트로 할 수 없는 것]
- 업체 PC 의 config.ini 내용 변경 (Slack 주소·계정 등) → 원격 데스크톱으로 접속해서 수정
- 3_run.bat 변경 → 원격 접속해서 손으로 교체
- 파이썬 자체·크롬 엔진 재설치 → 원격 접속
