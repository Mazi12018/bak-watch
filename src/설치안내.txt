보안관 설치일정 → Slack 알림 프로그램 설치 안내
==================================================

[이 프로그램이 하는 일]
- 2분마다 보안관 설치접수 일정표를 '조회만' 합니다. 로그인 말고는 아무 버튼도 누르지 않습니다.
- 바뀐 게 있으면 Slack 채널로 알립니다.
    [신규]     새 접수가 일정표에 올라옴
    [기사변경]  담당 기사가 바뀜 (이전 기사 → 새 기사)
    [일정변경]  날짜나 시간 구간이 바뀜
    [내용수정]  주소·제품·금액 등 내용이 바뀜
    [사라짐]   일정표에서 빠짐 (취소·삭제 또는 완료처리 — 보안관에서 확인 필요)
- 매일 08:00, 13:00 에 오늘~3일치 빈 구간(배정 가능한 구간)을 보냅니다.
- 3번 연속 조회에 실패하면 오류 알림, 복구되면 복구 알림을 보냅니다.


1단계. Slack 준비 (10분)
--------------------------------------------------
1) Slack에서 비공개 채널을 만듭니다. 예: #설치일정
   - 고객 주소·전화번호가 그대로 올라가므로 반드시 '비공개'로, 직원만 초대하세요.
2) https://api.slack.com/apps 접속 → Create New App → From scratch
   - 이름: 보안관알림 / 워크스페이스 선택
3) 왼쪽 메뉴 Incoming Webhooks → 켜기(On)
   → 아래 Add New Webhook to Workspace → #설치일정 채널 선택 → 허용
4) 생성된 주소(https://hooks.slack.com/services/...)를 복사해 둡니다.
   ※ 이 주소를 아는 사람은 누구나 채널에 글을 쓸 수 있으니 공유하지 마세요.


2단계. PC 준비 (항상 켜두는 윈도우 PC 1대)
--------------------------------------------------
1) 파이썬 설치: https://www.python.org/downloads/ 에서 내려받아 설치
   - 설치 첫 화면에서 "Add python.exe to PATH" 반드시 체크
2) 이 폴더를 PC의 원하는 위치에 둡니다. 예: C:\bak_watch
3) 1_install.bat 더블클릭 → 필요한 부품 설치 + config.ini 생성
4) config.ini 를 메모장으로 열어서 채웁니다.
   - company_id         : 로그인 화면의 '대표아이디'
   - user_id / password : 보안관 조회 전용 아이디·비밀번호
   - webhook_url        : 1단계에서 복사한 Slack 주소
   - 저장할 때 인코딩은 UTF-8 로 저장
5) 절전 끄기: 윈도우 설정 → 시스템 → 전원 → 화면 끄기는 상관없음, "절전 모드: 안 함"


3단계. 시험 실행
--------------------------------------------------
1) 2_test.bat 더블클릭
2) "로그인·조회 성공: 8일, 56개 구간, 접수 N건" 과 날짜별 구간·기사 목록이 나오면 성공입니다.
   - 보안관 화면과 건수·기사가 맞는지 눈으로 비교하세요.
   - 접수가 있는데 전부 0건으로 나오면 화면 구조가 예상과 다른 것입니다.
     이 경우 화면 내용을 알려주시면 수정합니다. (board_dump.html 파일은 고객정보가 들어 있으므로
     그대로 보내지 말고, 확인 후 삭제하세요.)
3) 시험 실행은 Slack으로 아무것도 보내지 않습니다.


4단계. 실제 실행 + 부팅 시 자동 시작
--------------------------------------------------
1) 3_run.bat 더블클릭 → 검은 창이 계속 떠 있으면 정상입니다. (닫으면 멈춥니다)
   - 처음 실행하면 Slack에 "[보안관 감시 시작]" 메시지가 옵니다. 이후 변경분부터 알립니다.
2) PC 재부팅 후에도 자동으로 켜지게 하기
   - 키보드 [윈도우키 + R] → shell:startup 입력 → 엔터
   - 열린 폴더에 3_run.bat 의 '바로가기'를 넣습니다. (파일 우클릭 → 바로가기 만들기 → 옮기기)
   - 윈도우 로그인이 되어 있어야 실행되므로, 자동 로그인 설정이 된 PC가 좋습니다.


운영 시 알아둘 점
--------------------------------------------------
- 알림은 최대 2분 늦습니다. 업무시간(07:30~20:00) 밖의 변경은 다음 날 아침 첫 확인 때 한꺼번에 옵니다.
- [사라짐]은 '취소'인지 '완료처리'인지 구분하지 못합니다. 첫 1~2주는 [사라짐] 알림이 실제로
  무엇이었는지 확인해 주세요. 완료처리 때도 매번 뜬다면 알려주세요. 걸러내도록 고치겠습니다.
- 같은 고객(같은 전화번호+주소)을 기준으로 추적합니다. 전화번호나 주소 자체를 고치면
  [사라짐] + [신규] 두 건으로 나옵니다.
- 보안관 화면이 개편되면 읽지 못할 수 있습니다. 그때는 "[보안관 감시 오류]" 알림이 옵니다.
- 보안관은 https가 아닌 http 접속이라 비밀번호가 암호화되지 않은 채 전송됩니다.
  그래서 반드시 '조회 전용' 아이디만 쓰세요.
- 설정 변경(확인 간격, 빈 구간 시각, 구간당 가능 건수 등)은 config.ini 수정 후 3_run 창을 닫고 다시 실행하면 됩니다.
- 기록: bak_watch.log (오류 원인 확인용), state.json (마지막 일정표 상태 — 고객정보 포함, 외부 반출 금지)


5단계. 그림 알림 설정 (휴대폰용 일정표 그림을 Slack에 올리기)
--------------------------------------------------
변경이 생길 때마다 오늘~3일 일정표를 휴대폰에서 보기 좋은 표 그림으로 만들어 올리고, 이전 그림은 지웁니다.
(칸 색: 초록=가능, 파랑=배정, 빨강=미배정, 회색=지난 시간 / 방금 바뀐 칸은 노란 테두리)
보안관 화면 캡처 모양을 원하면 config.ini [image] 의 style = capture 로 바꾸면 됩니다.
채널에는 항상 최신 일정표 그림 1장 + 무엇이 바뀌었는지 한 줄 요약이 남습니다.
매일 아침 첫 확인 때도 그날 일정표 그림을 1장 올립니다.

1) https://api.slack.com/apps → BAK Alert 앱 클릭
2) 왼쪽 OAuth & Permissions → 아래 Scopes → Bot Token Scopes → Add an OAuth Scope
   → files:write 추가, chat:write 추가
3) 같은 화면 위쪽 Install to Workspace (또는 Reinstall to Workspace) → 허용
4) Bot User OAuth Token (xoxb- 로 시작) → Copy
5) Slack 채널(#실시간-설치현황)에서 메시지 칸에  /invite @BAK Alert  입력 → 엔터
   (봇이 채널에 들어와 있어야 그림을 올릴 수 있습니다)
6) 채널 이름 클릭 → 맨 아래 '채널 ID' (C 로 시작) 복사
7) config.ini 맨 아래 [image] 칸에 bot_token, channel_id 붙여넣기
8) 1_install.bat 다시 실행 (그림 그리는 크롬 엔진 설치, 약 150MB)
9) 2_test.bat 실행 → "일정표 그림 만들기 성공", "Slack 봇 토큰 확인 성공" 이 나오면 완료
   폴더에 생긴 capture_test.png 를 열어 표가 보안관 일정과 맞는지 확인
10) 3_run.bat 창을 닫고 다시 실행

※ 봇 토큰은 Webhook 주소보다 권한이 큽니다. config.ini 를 다른 사람에게 보내지 마세요.
※ 그림 전송이 실패하면 자동으로 예전처럼 글 알림으로 보냅니다.
