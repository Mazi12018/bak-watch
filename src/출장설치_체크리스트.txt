보안관 설치일정 Slack 알림 — 다른 대리점 출장 설치 체크리스트
==================================================

[가기 전에 그 대리점에 미리 받아둘 것]
□ 보안관 '조회 전용' 계정 1개 (대표아이디 / 아이디 / 비밀번호)
   - 일정표(매장관리 > 설치접수)는 보이고, 등록·수정·삭제·배정은 안 되는 권한
   - 비밀번호는 1234 같은 쉬운 번호 금지 (보안관은 http 접속이라 암호화 안 됨)
□ 그 대리점의 Slack 워크스페이스 + 관리자 계정
   - 없으면 현장에서 새로 만듦 (무료로 가능, 10분)
   - 우리 회사(마지) Slack에 채널만 만들어 주는 방식은 비추천:
     그 대리점 고객 주소·전화번호가 우리 Slack에 쌓이게 됨
□ 항상 켜두는 윈도우 PC 1대 (사무실 PC 또는 벽 모니터용 PC)
   - 인터넷 가능, 윈도우 자동 로그인 되는 PC가 좋음
□ 기사님들 휴대폰에 Slack 앱 설치 + 그 워크스페이스 초대 (현장에서 같이 해도 됨)


[현장 설치 순서]  — 30~40분
1) PC에 파이썬 설치 (python.org → Downloads → Windows → Python 3.13.x 64-bit)
   □ 설치 첫 화면 "Add python.exe to PATH" 체크
2) bak_watch_배포용.zip 을 C:\ 에 압축 풀기 → C:\bak_watch
3) 1_install.bat 실행 (크롬 엔진 포함, 몇 분 걸림)
4) Slack 준비 (설치안내.txt 1단계, 5단계)
   □ 비공개 채널 만들기 (예: #설치일정)
   □ api.slack.com/apps → Create New App → Blank app → 이름 영어로 (예: BAK Alert)
   □ Incoming Webhooks 켜기 → Add New Webhook → 채널 선택 → 주소 복사
   □ OAuth & Permissions → 봇 토큰 범위에 files:write, chat:write 추가
   □ 맨 위 Reinstall → 허용 → Bot User OAuth Token (xoxb-…) 복사
   □ 채널에서 /invite @BAK Alert
   □ 채널 이름 클릭 → 맨 아래 채널 ID (C…) 복사
5) config.ini 메모장으로 열어 채우기 → Ctrl+S 저장
   □ [bak]   company_id / user_id  (password 칸은 비워 둠)
   □ 비밀번호_변경.bat 실행 → 보안관 비밀번호 입력 (윈도우 자격 증명에 저장)
   □ [slack] webhook_url
   □ [image] bot_token / channel_id
   □ [admin] site_name (대리점 이름) / admin_webhook_url / update_url  ← 본사 원격관리용, 마지에서 받은 값
   ※ = 뒤에 값만. 괄호·설명 글이 남아 있으면 안 됨
6) 2_test.bat 실행 → 아래 3줄 확인
   □ "로그인·조회 성공: 8일, … 접수 N건"  → 건수·기사가 보안관 화면과 같은지 비교
   □ "일정표 그림 만들기 성공"           → capture_test.png 열어서 표 확인
   □ "Slack 봇 토큰 확인 성공"
7) 3_run.bat 실행 → 2분 안에 Slack에
   □ [보안관 감시 시작] 글
   □ 오늘 일정표 그림 1장
   □ 마지 #대리점-관리 채널에 "[대리점이름] 프로그램 시작"
8) 자동 시작 등록
   □ 윈도우키+R → shell:startup → 3_run.bat 바로가기 넣기
   □ 설정 → 시스템 → 전원 → 절전 모드 "안 함"
9) 실제 변경 테스트 (가능하면)
   □ 미배정 건 하나 배정 → 2분 안에 [기사변경] 그림 올라오는지
10) 정리
   □ board_dump.html, capture_test.png 삭제 (고객정보 포함)
   □ 토큰·비밀번호를 카톡/메모에 남기지 않기
   □ 크롬 원격 데스크톱 설치 + PIN 설정 (사장님 동의 후)


[자주 나오는 문제]
- 2_test 에 그림 관련 줄이 아예 없음  → config.ini [image] 의 bot_token / channel_id 가 비어 있음
- "[그림 알림 꺼짐] … 비어 있거나 꺼진 값" → 그 항목을 채우기
- [그림 전송 실패] not_in_channel      → 채널에서 /invite @BAK Alert
- [그림 전송 실패] channel_not_found   → 채널 ID 다시 복사
- [그림 전송 실패] missing_scope       → 봇 권한 추가 후 Reinstall 안 함
- 알림이 2개씩 옴                      → 3_run 창이 두 개 떠 있음. 전부 닫고 하나만 실행
- 압축 풀었는데 이상하게 동작          → 압축파일 안에서 바로 실행한 경우. C:\ 에 풀었는지 확인
- 로그인 실패                          → 대표아이디·아이디·비밀번호 확인, 그 계정으로 직접 로그인해 일정표가 보이는지


[알아둘 점]
- PC 한 대에 대리점 하나만 돌릴 수 있음 (알림 중복 방지 기능 때문)
- 보안관 화면 구조가 바뀌면 모든 대리점이 같이 멈춤 → "[보안관 감시 오류]" 알림이 옴
- 설치일정만 지원. AS 접수 일정은 아직 안 됨
- 보안관 개발자에게 이 프로그램을 여러 대리점에서 쓴다고 미리 알려두기
- 사장님께 알릴 것: 조회만 함 / 마지로 작동상태·건수만 보고(고객정보 X) / 자동 업데이트 / 원격접속은 연락 후
