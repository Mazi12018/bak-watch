보안관 설치일정 알림 — 멈춤 수정판 (v2026.10.10) 안내
==================================================

[적용 방법]  — 5분
1) 받은 압축파일을 바탕화면 등 아무 곳에 풉니다. (C:\bak_watch 에 직접 풀지 마세요)
2) 푼 폴더 안의 '업데이트_적용.bat' 실행
   → 실행 중인 알림 창을 멈추고, C:\bak_watch 전체를 C:\bak_watch_백업_날짜시각 으로 백업한 뒤
     새 파일만 덮어씁니다. config.ini(설정)와 state.json(기록)은 건드리지 않습니다.
3) C:\bak_watch\비밀번호_변경.bat 실행 → 보안관 비밀번호 입력 (화면에 안 보임, 두 번)
   → 윈도우 자격 증명에 저장되고, config.ini 에 적혀 있던 비밀번호는 지워집니다.
4) C:\bak_watch\3_run.bat 실행
   → Slack 에 "프로그램 시작됨 (자동 재시작 감시 켜짐)" 이 오면 완료.
5) 아래 [윈도우 설정] 3가지 확인
6) 일주일 문제없으면 C:\bak_watch_백업_… 폴더는 지워도 됩니다.
   (백업 안의 config.ini 에는 예전 비밀번호가 그대로 있으므로 오래 두지 마세요)


[무엇이 바뀌었나]
1. 자동 재시작 감시기(watchdog.py) 추가
   - 3_run.bat 이 감시기를 켜고, 감시기가 알림 프로그램을 켜서 계속 지켜봅니다.
   - 프로그램이 꺼지면 20초 뒤 다시 켬
   - 켜져 있는데 8분 넘게 응답이 없으면(멈춤) 강제로 끄고 다시 켬
   - 다시 켤 때 Slack 에 "재시작됨 — 원인: …" 알림 (어느 단계에서 멈췄는지 포함)
   - 30분 안에 5번 넘게 재시작되면 알림을 멈추고 10분 간격으로 재시도, 1시간에 한 번만 알림
   - 남아서 쌓인 '그림용 크롬'을 정리 (직원이 쓰는 일반 크롬은 건드리지 않음)
2. PC 절전 감지
   - PC 가 잠들었다 깨어나면 "PC가 약 N분 동안 절전 상태였습니다" 알림 → 멈춤 원인이 절전인지 바로 알 수 있음
   - 프로그램이 켜져 있는 동안은 윈도우가 '절전 모드'로 들어가지 않게 요청 (화면 꺼짐·잠금은 그대로 허용)
3. 검은 창 클릭 멈춤 방지
   - 윈도우 검은 창을 마우스로 클릭하면 글자 선택 모드가 되면서 프로그램이 통째로 멈추는 문제가 있었음.
     출근한 직원이 창을 한 번 클릭하면 "창은 떠 있는데 갱신만 안 되는" 증상이 그대로 나옴. 이 기능을 끔.
4. Slack 상태줄 + 마지막 갱신 시각
   - 채널 맨 아래에 "● 정상 작동 중 · 마지막 확인 10/10 14:32" 한 줄이 생기고 2분마다 시각만 바뀜(알림 안 울림)
   - 이 시각이 멈춰 있으면 = 프로그램이 멈춘 것 → 직원이 바로 알 수 있음
   - 일정표 그림 오른쪽 위에도 "마지막 갱신 10/10 14:32" 표시
5. 하루 한 번 "정상 작동 중" 알림 (08:05)
   - 관리 채널(admin_webhook_url)이 있으면 그쪽으로, 없으면 일반 채널로
6. 로그(기록) 강화 — 원인 추적용
   - bak_watch.log : 2분마다 "조회 OK · 접수 N건 · 걸린 시간", 공백(멈춤·절전) 감지, 시작 환경
   - watchdog.log  : 시작/재시작/멈춤 감지/절전 감지/남은 크롬 개수 (1시간마다)
   - 둘 다 C:\bak_watch 안. 크기가 차면 자동으로 오래된 것부터 지움.
7. 비밀번호 보관 방식 변경
   - 예전: config.ini 에 글자 그대로 저장 (메모장으로 열면 누구나 보임)
   - 지금: 윈도우 '자격 증명 관리자'에 암호화 저장. config.ini 에는 비밀번호가 없음.
   - 프로그램 코드(bak_watch.py)와 GitHub 에는 원래부터 비밀번호가 없음.
8. 그림 만들 때 크롬 시간제한(최대 60초) 추가 — 크롬이 응답 없을 때 무한정 기다리지 않게


[윈도우 설정 — 직접 해야 하는 것]
1. 절전 끄기:  설정 → 시스템 → 전원 및 배터리 → 화면 및 절전
   → "전원 연결 시 다음 시간 후 절전 모드로 전환" = 안 함   (화면 끄기는 상관없음)
   ※ 노트북이면 덮개를 닫았을 때 동작도 '아무것도 안 함'으로: 제어판 → 전원 옵션 → 덮개를 닫으면 수행되는 작업
2. 윈도우 업데이트 재시작 시간:  설정 → Windows 업데이트 → 고급 옵션 → 사용 시간
   → 07:00 ~ 21:00 으로 (이 시간엔 업데이트로 자동 재부팅 안 함)
3. 재부팅 후 자동 실행:  윈도우키+R → shell:startup → 3_run.bat 바로가기가 있는지 확인
   ※ 윈도우에 로그인이 되어야 실행됨. 재부팅 후 비밀번호 입력 화면에서 멈춰 있으면 실행 안 됨.


[보안관 비밀번호를 바꿨을 때]
- 보안관에서 slack 계정 비밀번호를 바꾼 뒤 → C:\bak_watch\비밀번호_변경.bat 실행 → 새 비밀번호 입력. 끝.
- 프로그램을 다시 켤 필요 없음 (다음 로그인 때 새 비밀번호를 자동으로 씀).
- config.ini 는 고칠 필요 없음.


[멈췄을 때 저에게 보낼 것]
- C:\bak_watch\bak_watch.log, watchdog.log 두 파일 (고객정보·비밀번호는 들어 있지 않음)
- Slack 에 온 "재시작됨 — 원인: …" 문구
